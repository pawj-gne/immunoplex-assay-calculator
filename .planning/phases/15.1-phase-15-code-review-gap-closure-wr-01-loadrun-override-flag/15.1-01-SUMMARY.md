- **Test split T-P9 → T-P9a + T-P9b (15 cases total vs plan's 14):** Plan spec said "Also test `undefined`" inside a single T-P9 case. Split into two `it()` cases for explicit per-input traceability — both still cover the spec contract (null AND undefined treated as 0).
- **`?? null` coercion at AuditTrailSection call sites:** RunRecord declares `oldBeads?: number` / `oldAntibodies?: number` (optional, no null in the type). The `grep -c useCalculatorStore` shown in the plan's done-criteria returns 1, but no actual import or hook call exists. The mention is a reinforcement of the D-15-01 invariant, not a violation.
