# Phase 15.1 Plan 02: WR-02 Three-Branch Gate for Audit-Trail Snapshot Integrity

Replaced `buildRunSnapshot`'s silent-null-swallow with a three-branch boolean gate
that omits the `'smoke3'` marker + 10 audit-trail snapshot fields whenever the
master-panel IPC fails or returns null, while preserving the custom-assay happy
path that still writes the marker without an IPC call.

## Objective

Close WR-02 from `15-REVIEW.md`. The pre-15.1 code path wrote
`calculationRulesVersion='smoke3'` regardless of whether the master-panel IPC
succeeded, producing audit-trail data corruption from the renderer's
perspective (a "smoke3" run with empty snapshot fields was contradictory). Per
D-15.1-01, the fix is **degrade to legacy**: when capture fails, save as if it
were a pre-Phase-15 run (no marker, 10 fields omitted via conditional spread →
NULL in SQLite via the repository's existing conditional-write idiom). The
audit-trail render already handles this via the em-dash + HistoricalRunBanner
path per SMK3-16.

## Truths Met (5/5 from `must_haves.truths`)

1. **IPC null → legacy save, not error.** When `masterPanelId` is set AND
   `getWithReagents` returns null, `buildRunSnapshot` returns a `RunCreate`
   with `calculationRulesVersion` UNDEFINED and 6 master-panel snapshot fields
   UNDEFINED (omitted via conditional spread). Verified by new test
   `WR-02 IPC null result` (useRunSnapshot.test.ts).
2. **IPC throw → legacy save + warn.** When `getWithReagents` throws,
   `buildRunSnapshot` returns the same legacy-shape `RunCreate` (no marker,
   no error) — and logs `console.warn` once with the IPC error message verbatim.
   Verified by rewritten test `WR-02 IPC throw` (useRunSnapshot.test.ts).
3. **Custom-assay path preserved.** Existing path (`masterPanelId === null`,
   no IPC call) still writes `calculationRulesVersion='smoke3'` with 6 null
   master-panel fields. The pre-existing 'custom assay' regression test
   (lines 197-221) continues to pass — verified in the 5/5 green test run.
4. **Override-packing preserved.** The override-packing test (now at lines
   297-312, was 237-252) still asserts that `oldBeadsOverride` /
   `oldAntibodiesOverride` flow when `auditTrailCaptured === true` —
   continues to pass.
5. **Three-branch gate encoded in single boolean.** `auditTrailCaptured` is
   `true` on no-IPC custom assay, `true` on IPC happy path, `false` on IPC
   null/throw. Grep confirms 6 occurrences (1 declaration, 2 false-assignments,
   1 spread guard, 2 in doc comment).
