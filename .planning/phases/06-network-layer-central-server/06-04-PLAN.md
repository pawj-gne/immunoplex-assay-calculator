**Create src/renderer/src/stores/networkStore.ts:**
```typescript
import { create } from 'zustand'

interface NetworkState {
  // Optimistic default: true — avoids flash of offline banner on server/local-only machines.
  // The reconnect poller (5s interval) will push the real state within ~5s on client machines.
  // Server machines and local-only machines never receive a 'connection:status' false event.
  online: boolean
  setOnline: (online: boolean) => void
}

export const useNetworkStore = create<NetworkState>((set) => ({
  online: true,
  setOnline: (online) => set({ online })
}))
```

**Create src/renderer/src/features/network/OfflineBanner.tsx:**

Per D-04 (CONTEXT.md §Offline Indicator) — verbatim copy text "Working offline — saves stored locally":
```tsx
import { useNetworkStore } from '../../stores/networkStore'

/**
 * D-04: Persistent offline indicator. Appears below the app header when the
 * client machine cannot reach the server. Disappears automatically on reconnect.
 * Placed in App.tsx between <header> and <main> so it spans full width.
 */
export function OfflineBanner(): JSX.Element | null {
  const online = useNetworkStore((s) => s.online)
  if (online) return null
  return (
    <div
      role="status"
      aria-live="polite"
      className="w-full bg-yellow-50 border-b border-yellow-200 px-6 py-2 text-sm font-medium text-yellow-800"
    >
      Working offline — saves stored locally
    </div>
  )
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| IPC push → renderer | connection:status event arrives from main process via contextBridge; renderer cannot distinguish real reconnect events from spoofed events |
| machineName in RunList | machineName is os.hostname() from the saving machine; displayed as-is without sanitization |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-13 | Tampering | connection:status IPC event | accept | The event only sets a boolean in networkStore; no security-sensitive action is gated on online state (saves still work in both states). Spoofing the event could cause the banner to appear/disappear incorrectly — cosmetic impact only. |
| T-06-14 | Information Disclosure | machineName in RunList Source column | accept | Displays OS hostname; acceptable for internal lab display. No PII beyond workstation names. |
| T-06-15 | Tampering | XSS via machineName display | mitigate | machineName is rendered as React text children (not dangerouslySetInnerHTML); React escapes content automatically. No XSS risk. |
</threat_model>
