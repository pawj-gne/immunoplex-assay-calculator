# Phase 6 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Scope Note

Phase 6 is primarily a backend/IPC phase. It introduces exactly **two renderer-visible changes**:

1. **Offline banner** — persistent top-of-app indicator when the client machine cannot reach the server (D-04 from CONTEXT.md).
2. **RunList machine/source column** — adds a "Source" column to the Past Runs list rows showing machine name and offline-save attribution (D-02 from CONTEXT.md).

All other UI (wizard, manage page, calculator) is unchanged. Design decisions below apply only to these two additions and must maintain consistency with the existing design patterns in `src/renderer/src/`.

## Component Inventory

### New: OfflineBanner

**Location:** `src/renderer/src/features/network/OfflineBanner.tsx`

**Placement in App.tsx:** Between `<header>` and `<main>` — full-width, spans edge-to-edge. Must not be nested inside the `max-w-4xl` container. Renders only when `online === false` in `useNetworkStore`.

**Anatomy:**
```
[full-width div — bg-yellow-50 border-b border-yellow-200 px-6 py-2]
  [text — text-sm font-medium text-yellow-800]
    "Working offline — saves stored locally"
```

**States:**
- `online === true` → renders `null` (removed from DOM entirely)
- `online === false` → renders full-width yellow banner

**Interaction:** None. Read-only display. No close button. Disappears automatically when `useNetworkStore.setOnline(true)` is called by the reconnect poller IPC push.

**Accessibility:** `role="status"` on the banner div so screen readers announce state changes. `aria-live="polite"` — the offline state change is important but not emergency-level.

---

### Modified: RunList — Source Column

**Existing file:** `src/renderer/src/features/run/components/RunList.tsx`

**Change:** Add an 8th column to the existing 7-column `grid-cols-7` layout. New layout: `grid-cols-8`.

**New column header label:** "Source"

**New column cell content:**
```tsx
function displayRunSource(run: RunRecord): string {
  if (!run.machineName) return ''            // pre-Phase-6 row
  if (run.isOfflineSave) return `${run.machineName} — offline save`
  return run.machineName
}
```

**Visual treatment for offline-save cell:** Render the "— offline save" suffix in a `<span>` with `text-yellow-700` to draw the eye to conflict rows. The machine name portion renders in standard `text-[var(--color-foreground)]`.

Specific markup for offline save cell:
```tsx
<div>
  <div className="text-[var(--color-muted)]">Source</div>
  <div className="text-[var(--color-foreground)] font-medium">
    {run.machineName ?? ''}
    {run.isOfflineSave && (
      <span className="text-yellow-700"> — offline save</span>
    )}
  </div>
</div>
```

### New: useNetworkStore (Zustand)

**Location:** `src/renderer/src/stores/networkStore.ts`

**Shape:**
```typescript
interface NetworkState {
  online: boolean
  setOnline: (online: boolean) => void
}
```

**Initial state:** `online: true` — assume connected at launch. The reconnect poller pushes an update within ~5 seconds if the server is unreachable (per RESEARCH.md Pattern 5). Starting optimistic avoids a flash of the offline banner on server machines and local-only machines that are always "online" from their own perspective.

## Interaction Contract

### Offline State Transitions

| Event | Before | After | Visual Change |
|-------|--------|-------|---------------|
| Server unreachable detected | online | offline | OfflineBanner appears below header |
| Server reconnected detected | offline | online | OfflineBanner disappears (null render) |
| App launches, no config.json | — | stays online=true | No banner — local-only mode is always "online" for its own DB |
| App launches, isServer=true | — | stays online=true | No banner — server machine routes direct |

Transition animation: none. The banner appears/disappears instantly via React conditional render (`if (online) return null`). Smooth fade would require additional state; not warranted for a status indicator that must be immediate and clear.

### RunList Column Display

| Row type | Source cell content | Visual treatment |
|----------|---------------------|-----------------|
| Pre-Phase-6 row (`machineName = NULL`) | *(empty)* | Standard muted label, blank value |
| Server/local-only save | `LAB-PC-01` (or hostname) | Standard foreground text |
| Offline save | `LAB-PC-02 — offline save` | Machine name in foreground, " — offline save" in yellow-700 |
