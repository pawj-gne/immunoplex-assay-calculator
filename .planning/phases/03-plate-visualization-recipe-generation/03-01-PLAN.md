       - Return { layouts: PlateLayout[], hasOutputs: boolean }
       - Use useMemo for derived computation

       Key logic:
       - STANDARD_COLS = [1, 2, 3]
       - For singles: each sample = 1 well
       - For duplicates: each sample = 2 wells (fill row by row)
       - Sample numbering continues across plates
