 * Phase 15 SMK3-15/16: composed read for the audit-trail snapshot.
 * Returns the master_panels row plus its master_panel_reagents children
 * (0..3 rows: beads, antibodies, sape) in a single call so the renderer's
 * buildRunSnapshot can pack the 6 master-panel-derived fields onto the
 * runs row at save time. Returns null when the master_panel id is unknown
 * (defensive — should not happen in normal flow because selectionStore
 * carries a valid masterPanelId post-selectPanel).

getByIdWithReagents(id: string): {
  masterPanel: MasterPanel
  reagents: MasterPanelReagent[]
} | null {
  const masterPanel = masterPanelRepository.getById(id)
  if (!masterPanel) return null
  const reagents = masterPanelReagentRepository.findByMasterPanelId(id)
  return { masterPanel, reagents }
}

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer to main IPC (`master-panel:get-with-reagents`) | Renderer-supplied `masterPanelId: string` crosses into main-process repository read. typeof guard at the handler is the validation layer. |
| disk read (SQLite via better-sqlite3) | Read-only path from local SQLite into renderer memory. No write surface introduced. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-06 | Tampering | renderer-supplied `masterPanelId` could be an arbitrary string | mitigate | typeof string guard at handler entry; downstream repository uses parameterized Drizzle query (no SQL injection surface). Unknown ids return null cleanly. |
| T-15-07 | Information Disclosure | Read returns SMK3-DIL-01 verbatim diluent strings + sapeName, which may include lab-internal vendor metadata | accept | Same trust domain as the renderer; the data already crosses the IPC boundary via panel/analyte/import channels. No new disclosure surface. |
| T-15-08 | Denial of Service | Repeated calls during keystroke-driven re-renders could spam the IPC | mitigate | Plan 15-03 explicitly fires this IPC ONLY on Save click (not in `useMemo` / on every keystroke). RESEARCH Open Risk #3 is the design constraint. |
</threat_model>
