1. **Schema (src/main/db/schema.ts):** Add:
   - `runs` table: id (text pk), userName, operatorName, runDate, sampleType, sampleCount (integer), replicateMode (text: 'singles' | 'duplicates'), requestType (text: 'premix' | 'premix_singles' | 'custom'), platformId (FK platforms.id), speciesId (FK species.id), panelId (FK premixPanels.id, nullable), volumePerWell (real), deadVolume (real), platesJson (text, stores the `Record<plateNumber, string[]>` shape), hamiltonAssignment (text nullable), tubeBlockPositions (text nullable), troughPositions (text nullable), createdAt, updatedAt.
   - `runSingleAnalytes` join table: id, runId (FK runs.id), analyteId (FK analytes.id), createdAt.
   - Add `$inferSelect` / `$inferInsert` type aliases for each table (mirror the existing panelAnalytes pattern at the bottom of schema.ts).

2. **Shared types (src/shared/types/run.ts):** Define:
   - `RunRecord` — the hydrated read shape with `plates: Record<number, string[]>` (deserialized from platesJson) and `singleAnalyteIds: string[]` (from the join table).
   - `RunCreate` — the input shape matching Zod below. Note: `plates` is `Record<number, string[]>` (NOT `Set<string>`, because Zod and JSON can't serialize Set; the renderer must convert `Array.from(set)` before calling the IPC).

3. **Validation (src/shared/validation/run.ts):** Create `runCreateSchema`:
   ```ts
   z.object({
     userName: z.string().min(1),
     operatorName: z.string().min(1),
     runDate: z.string().min(1),            // ISO date/datetime string; don't over-constrain
     sampleType: z.string().min(1),
     sampleCount: z.number().int().positive(),
     replicateMode: z.enum(['singles', 'duplicates']),
     requestType: z.enum(['premix', 'premix_singles', 'custom']),
     platformId: z.string().min(1),
     speciesId: z.string().min(1),
     panelId: z.string().min(1).nullable(),
     volumePerWell: z.number().positive(),
     deadVolume: z.number().nonnegative(),
     plates: z.record(
       z.string().regex(/^\d+$/),           // plate number as stringified key (JSON keys are strings)
       z.array(z.string().regex(/^[A-H](?:[1-9]|1[0-2])$/))
     ),
     singleAnalyteIds: z.array(z.string().min(1)).max(5).or(z.array(z.string().min(1))),
     hamiltonAssignment: z.string().nullable().optional(),
     tubeBlockPositions: z.string().nullable().optional(),
     troughPositions: z.string().nullable().optional()
   })
   ```
   Note: `.max(5)` only applies when requestType is 'premix_singles' — enforce the max-5 rule with a `.superRefine` that checks `requestType === 'premix_singles' => singleAnalyteIds.length <= 5`. Don't use `.uuid()` — existing platform/species/analyte IDs in this codebase are `crypto.randomUUID()` output but the existing schemas in src/shared/validation/platform.ts use `z.string().min(1)`, so match that convention.

4. **Repository (src/main/db/repositories/run.ts):** Follow `platformRepository` structure (src/main/db/repositories/platform.ts) for style. Provide:
   - `getAll(): RunSummary[]` — select from runs ordered by createdAt desc; don't hydrate child arrays (keep the list query cheap). `RunSummary` can be `Run` (raw table row) or a trimmed projection — pick whichever Task 1 research shows the existing list endpoints use.
   - `getById(id): RunRecord | null` — select run row, `JSON.parse(platesJson)` into `Record<number, string[]>`, select runSingleAnalytes.analyteId list, return combined shape.
   - `create(data: RunCreate): RunRecord` — use `getSqlite().transaction(...)` (see the pattern described in 04-RESEARCH.md Pattern 1) to insert runs row (with `platesJson = JSON.stringify(data.plates)`) and then insert one runSingleAnalytes row per analyteId. Return the hydrated record via `getById`.
   - `delete(id): void` — delete runSingleAnalytes first, then runs (FK order).

5. **Migration:** Run `npx drizzle-kit generate` then `npx drizzle-kit push` to produce and apply the migration. Then inspect src/main/db/migrate.ts and confirm it runs the generated migration at app startup. If `migrate.ts` requires a list/glob of migration files, update it; otherwise leave alone.

6. Typecheck: `npx tsc --noEmit`.
