   - `delete(id)`: delete runAnalytes first, then run (foreign key order)
   - Use `crypto.randomUUID()` for IDs, `new Date().toISOString()` for timestamps

  <action>
1. Add to channels.ts IPC_CHANNELS object:
   ```
   RUN_GET_ALL: 'run:get-all',
   RUN_GET_BY_ID: 'run:get-by-id',
   RUN_CREATE: 'run:create',
   RUN_DELETE: 'run:delete',
   ```

2. Create src/main/ipc/run.ts following the exact pattern in platform.ts:
   - `registerRunHandlers()` function
   - RUN_GET_ALL -> runRepository.getAll()
   - RUN_GET_BY_ID -> runRepository.getById(id)
   - RUN_CREATE -> parse with runCreateSchema, then runRepository.create(parsed)
   - RUN_DELETE -> runRepository.delete(id)

3. Register in src/main/ipc/index.ts: import and call registerRunHandlers()

4. Add to src/preload/index.ts electronAPI object:
   ```
   run: {
     getAll: () => ipcRenderer.invoke(IPC_CHANNELS.RUN_GET_ALL),
     getById: (id: string) => ipcRenderer.invoke(IPC_CHANNELS.RUN_GET_BY_ID, id),
     create: (data: unknown) => ipcRenderer.invoke(IPC_CHANNELS.RUN_CREATE, data),
     delete: (id: string) => ipcRenderer.invoke(IPC_CHANNELS.RUN_DELETE, id)
   }
   ```

5. Update src/preload/index.d.ts to add the run API type declarations matching the above methods.
