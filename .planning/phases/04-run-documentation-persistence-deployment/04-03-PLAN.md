<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 3: Windows workstation smoke test (human in the loop)</name>
  <what-built>
- Windows NSIS `.exe` installer for Immunoplex Assay Calculator, cross-compiled from macOS.
- Native better-sqlite3 module and drizzle migrations included in the installer payload.
- First full end-to-end packaged build of the app.
  </what-built>
  <how-to-verify>
Per `CLAUDE.md` -> `Workflows -> Testing (Windows-only)`, all runtime verification happens on Windows. Copy the `.exe` produced in Task 2 to the Windows workstation and walk through every step below in order. Record the first failure (if any) verbatim including any error dialog text.

1. **Transfer**: Copy `dist/immunoplex-assay-calculator-<version>-setup.exe` from the Mac to the Windows PC (USB, network share, or artifact download -- whatever is set up).
2. **Install**: Double-click the installer. Expect NSIS wizard. Click through with defaults. Expect install to complete without an admin elevation prompt failure, and for a Start Menu entry + desktop shortcut to be created.
3. **Launch**: Open the app from the desktop shortcut. Expect the main UI to render within ~5 seconds. If it flashes and dies, that is almost always a native module failure -- capture the error and stop.
4. **Platform select**: Pick a platform (e.g. Milliplex). Expect the platform's analytes/panels to load from the bundled SQLite DB (first launch will seed from migrations).
5. **Analyte select**: Choose a premix panel OR a custom analyte set. Expect the selection UI to respond without console errors.
6. **Sample plate assignment**: Enter sample count, pick replicate mode (singlet/duplicate), and assign samples on the plate grid. Expect the calculator outputs (volumes, master mix, single-analyte additions) to display.
7. **Save run**: Fill in the run metadata form (user, operator, date, sample type, Hamilton assignment, etc.) and click Save. Expect a success indicator and for the run to appear in the run list.
8. **Close**: Fully close the app (X button, confirm process exits in Task Manager).
9. **Reopen**: Relaunch from the shortcut. Expect the app to start and the previously saved run to still appear in the run list.
10. **Load run**: Click Load on the saved run. Expect the metadata form and calculator inputs to repopulate from the saved record.
11. **Uninstall (optional cleanup)**: Uninstall via Settings -> Apps if this was a scratch install. Confirm the app's userData folder either persists or is cleaned per your preference -- note the behavior either way.

If any step fails, capture: (a) which step, (b) exact error text or screenshot, (c) whether the app stayed open or crashed. Return that verbatim. Do not attempt fixes from the Windows side.
  </how-to-verify>
  <resume-signal>Type "approved" if all 10 required steps pass, or paste the failure details described above.</resume-signal>
