<objective>
Fix UI-01: Selecting a premix panel currently shows analytes from ALL panels simultaneously, and both are selectable. Domain expert flagged this as a correctness bug — Panel I and Panel II must be mutually exclusive.

Per D-4.1-04, the analyte grid must be scoped to a single premix selection at a time:

| Premix selection | Analyte section content | Section label |
|------------------|-------------------------|---------------|
| "No Premix (Custom Assay)" | **Master list** — all analytes for this platform+species | "Analytes" |
| Premix Panel I | Panel I's analytes only | Panel I's name |
| Any specific premix | That premix's analytes only | Premix name |

Per D-4.1-05, the generic label "Analytes" is used for the master list in 4.1 (vendor-specific terms like "Singleplex" ship in v2 with the xlsx upload format).

Purpose: Operators cannot mix analytes across premixes. Switching premixes replaces the visible set (and clears any stale singles from the prior scope).

Output: `AnalyteGrid` renders ONE scoped section. `AnalyteSelectionPanel` computes `scopedAnalytes` + `sectionLabel` from `selectedPanelId` and passes them to `AnalyteGrid`. `selectionStore.selectPanel` clears `selectedSingleIds` on every transition.
</objective>

interface AnalyteGridProps {
  scopedAnalytes: Analyte[]

  selectedSingleIds: string[]
  canAddMoreSingles: boolean
  onToggleSingle: (analyteId: string) => void
}

export function AnalyteGrid({
  scopedAnalytes,

  selectedSingleIds,
  canAddMoreSingles,
  onToggleSingle
}: AnalyteGridProps) {
  if (scopedAnalytes.length === 0) {

                isDisabled={isDisabled}

            )

}
