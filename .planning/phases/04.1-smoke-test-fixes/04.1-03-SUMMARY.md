## Decisions Made

- **Resolver reuse, not extraction:** Kept `speciesName` inline in RunList matching `platformName`/`operatorName` rather than introducing a shared `features/run/utils/nameResolvers.ts`. Matches prior-phase style and keeps the file self-contained; revisit if a 4th resolver ever lands.
- **Banner location below `<h3>` (inside card):** Keeps the banner visually scoped to the Metadata card and preserves the card's rounded border as the top visual element on the page. An above-heading placement would have floated outside the card.
- **Panel fallback `'Custom'`:** Aligns with `FinalizedRunHeader.tsx` line 59 (`panelId ? (panel?.name ?? record.panelId) : 'Custom'`). The operator sees the same "Custom" label on both the Document & Save step and the Finalized view when no premix panel is selected.
