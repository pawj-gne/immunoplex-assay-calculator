## Page 2: Panel & Analyte Selection Redesign

### Layout

```
┌─────────────────────────────────────────────┬──────────────────┐
│  PREMIX PANEL SELECTION (top)               │                  │
│  [Panel A] [Panel B] [Panel C]              │  SELECTED        │
│  (one selectable at a time)                 │  SIDEBAR         │
├─────────────────────────────────────────────┤                  │
│  ANALYTE GRID (middle)                      │  ▼ Panel A       │
│                                             │    · IL-6        │
│  Cards: name + bead region + concentration  │    · TNF-α       │
│  Grouped by panel membership                │    · IL-1β       │
│                                             │  ──────────      │
│  ── Panel A ─────────────────               │  + IL-10         │
│  [IL-6    ] [TNF-α   ] [IL-1β   ]          │  + IFN-γ         │
│  [BR: 27  ] [BR: 75  ] [BR: 46  ]          │                  │
│  [20x     ] [20x     ] [20x     ] ← grayed │                  │
│                                             │                  │
│  ── All Analytes ────────────               │                  │
│  [IL-10   ] [IFN-γ   ]                     │                  │
│  [BR: 12  ] [BR: 21  ]                     │                  │
│  [20x     ] [20x     ] ← selectable        │                  │
└─────────────────────────────────────────────┴──────────────────┘
```

### Behavior

- **Premix selection**: One panel at a time. Selecting a new one replaces previous.
- **Graying**: Selecting a premix grays out its member analytes in the grid (can't double-select).
- **Singles**: Can add up to 5 individual singles on top of premix.
- **Sidebar**: Shows selected panel name with nested member analytes + individual singles.
- **Unselect premix**: Removes premix analytes from sidebar but keeps individual selections.
- **"All Analytes" section**: Shows analytes not belonging to any panel.

### Sample Count Input

- **Slider + editable number field** (replaces current ticker input)
- Field starts **blank** (not 0), default sample count is 0
- Click-to-type without friction (no needing to clear "0" first)
- Slider and field stay in sync

### Auto-Fill Behavior

1. Enter total samples (e.g., 200)
2. UI auto-calculates **minimum plates** needed
3. Pre-fills wells **sequentially** across plates
4. "Samples Remaining: 0" after auto-fill

### Plate Management

- **Add Plate**: User can add plates beyond the auto-calculated minimum
- **Remove Plate**: User can remove plates (reassigns samples to Remaining)
- **Clear Plate**: Clears all wells on current plate, adds them back to Remaining
- **Paging**: Navigate between plates with ◀ ▶ controls

### Well Interaction

- **Click well**: Toggles individual well (filled → empty or empty → filled)
- **Click + drag**: Select range of wells (like Excel)
- **Ctrl + click**: Toggle individual wells without affecting others
- **Shift + click**: Extend selection from last click
- **Clear Plate button**: Clears all wells on current plate for full re-selection
- **Samples Remaining** updates live as wells are toggled

### Duplicates Mode

In duplicates mode, selecting a sample auto-fills both wells of the pair:
- Horizontal pairs: columns 4-5, 6-7, 8-9, 10-11
- Vertical pairs: column 12 rows A-D → E-H
- Clicking one well of a pair fills/clears both
- 36 samples per plate maximum

## State Management Considerations

The interactive plate assignment introduces new state:
- Per-plate well selections (which wells are filled on each plate)
- Samples remaining count
- Currently `calculatorStore` drives plate layout derivatively
- New model: plate layout becomes editable state, not just derived

This is a fundamental shift — plates go from **computed** (derived from sample count) to **editable** (user can modify individual wells). The sample count input and plate state need to stay in sync bidirectionally.
