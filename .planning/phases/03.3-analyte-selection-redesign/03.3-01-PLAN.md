**Create `src/renderer/src/stores/plateStore.ts`:**

Zustand store managing editable plate state. Key design: ONE-WAY data flow with manual override. sampleCount is INPUT, plate wells are OUTPUT that can be manually adjusted.

Interface:
```typescript
interface PlateState {
  // State
  plates: Record<number, Set<string>>  // plateNumber (1-indexed) -> set of filled well IDs (e.g., "A4")
  activePlate: number  // currently viewed plate (1-indexed)
  sampleCount: number  // committed sample count (0 = blank)
  replicateMode: 'singles' | 'duplicates'

  // Actions
  setSampleCount: (count: number) => void  // sets count AND auto-fills
  setReplicateMode: (mode: 'singles' | 'duplicates') => void
  autoFill: () => void  // fills plates sequentially from sampleCount
  toggleWell: (plateNumber: number, wellId: string) => void
  setWellRange: (plateNumber: number, wellIds: Set<string>, filled: boolean) => void
  addPlate: () => void
  removePlate: (plateNumber: number) => void
  clearPlate: (plateNumber: number) => void
  setActivePlate: (plateNumber: number) => void
  reset: () => void

  // Computed
  getPlateCount: () => number
  getTotalAssigned: () => number
  getSamplesRemaining: () => number
  getMinPlatesNeeded: () => number
  getPlateWells: (plateNumber: number) => Set<string>
}
```

Implementation details:
- `setSampleCount`: Updates sampleCount then calls `autoFill()`
- `setReplicateMode`: Updates mode then calls `autoFill()`
- `autoFill()`:
  1. Calculate min plates needed: `Math.ceil(sampleCount / wellsPerPlate)` where wellsPerPlate is 72 (singles) or 36 (duplicates)
  2. Ensure at least that many plates exist in `plates` record
  3. Fill wells sequentially: column-first order (A4, B4, C4... A5, B5...) for singles. For duplicates, fill pairs using getDuplicatePair.
  4. Clear any excess plates beyond needed
  5. Standards (cols 1-3) are NEVER included in the fillable wells set
- `toggleWell`: In duplicates mode, toggling one well also toggles its pair (using getDuplicatePair)
- `setWellRange`: Batch toggle for drag selection; in duplicates mode, auto-include pairs
- `getSamplesRemaining`: `sampleCount - getTotalAssigned()`. In duplicates mode, each pair = 1 sample (divide assigned well count by 2).
- `getMinPlatesNeeded`: `Math.ceil(sampleCount / wellsPerPlate)`, minimum 1 if sampleCount > 0
- Use plain objects with `Record<number, Set<string>>` for plates (Zustand handles immutability)
- Initial state: sampleCount = 0, plates = { 1: new Set() }, activePlate = 1, replicateMode = 'singles'
