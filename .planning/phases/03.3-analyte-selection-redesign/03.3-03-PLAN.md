Create a custom React hook that manages mouse-based grid cell selection with click, drag, Ctrl+click, and Shift+click support for the 96-well plate.

**Interface:**
```typescript
interface UseWellSelectionOptions {
  standardCols: readonly number[]  // 1-indexed columns that are standards (not selectable) - [1,2,3]
  replicateMode: 'singles' | 'duplicates'
  filledWells: Set<string>  // current state from plateStore
  onSelectionChange: (wellIds: Set<string>, action: 'add' | 'remove') => void
}

interface UseWellSelectionReturn {
  hoveredWells: Set<string>  // preview during drag (visual only)
  handleMouseDown: (row: number, col: number, event: React.MouseEvent) => void
  handleMouseEnter: (row: number, col: number) => void
  handleMouseUp: () => void
}
```

**Key design decisions:**
- Use `useRef` for drag state (`isDragging`, `dragStart`, `dragAction`) to avoid re-renders during mouse movement
- Use `useState` only for `hoveredWells` (needed for visual feedback)
- The hook does NOT own the selection state - it calls `onSelectionChange` to delegate to plateStore
- `filledWells` is passed in as a prop (from plateStore) for determining toggle behavior

**Implementation details:**

1. **`handleMouseDown(row, col, event)`:**
   - If col is a standard column (1-indexed cols 1-3), return immediately
   - Set `isDragging.current = true`, `dragStart.current = { row, col }`
   - Determine drag action: if the well is already filled, action = 'remove'; else action = 'add'. Store in `dragAction.current`.
   - **Shift+click:** If `event.shiftKey` and `lastClicked.current` exists, get all cells in rectangle from lastClicked to current, apply the drag action, call `onSelectionChange(range, dragAction)`
   - **Ctrl+click (or metaKey):** Toggle single well. Call `onSelectionChange(new Set([wellId]), filledWells.has(wellId) ? 'remove' : 'add')`
   - **Plain click:** Start new selection area. Set `hoveredWells` to the clicked well (and its pair in duplicates mode)
   - Update `lastClicked.current = { row, col }`

2. **`handleMouseEnter(row, col)`:**
   - If not dragging, return
   - Calculate rectangle from `dragStart.current` to current `{ row, col }`
   - Set `hoveredWells` to all cells in that rectangle (excluding standard cols)
   - In duplicates mode, include paired wells via `getDuplicatePair`

3. **`handleMouseUp()`:**
   - If `isDragging.current` and `hoveredWells.size > 0`:
     - Call `onSelectionChange(hoveredWells, dragAction.current)`
   - Reset: `isDragging.current = false`, `dragStart.current = null`, `setHoveredWells(new Set())`

4. **Window mouseup listener:**
   - Attach `mouseup` event listener to `window` in a `useEffect` to catch releases outside the grid
   - On window mouseup: if dragging, finalize with current hoveredWells, then reset

5. **Helper: `getCellsInRange(start, end)`:**
   - Calculate rectangle: minRow/maxRow, minCol/maxCol
   - For each cell in rectangle:
     - Skip if standard column
     - Add wellId (e.g., "A4" = row 0, col 3 -> `${String.fromCharCode(65 + row)}${col + 1}`)
     - In duplicates mode, also add the paired well via `getDuplicatePair(row, col)`
   - Return `Set<string>`

6. **Helper: `toWellId(row, col)`:** `${String.fromCharCode(65 + row)}${col + 1}` (0-indexed row/col to well ID like "A4")

7. **Helper: `isStandardCol(col)`:** `standardCols.includes(col + 1)` (convert 0-indexed col to 1-indexed for check)

Import `getDuplicatePair` from `../../../../../shared/constants/calculator`.

**Performance:** Only `hoveredWells` is React state (triggers re-render for visual preview). All drag tracking uses refs. This means only mouse enter events cause re-renders, not mouse move.

**Rewrite `WellCell.tsx` to support interactive states:**

Wrap with `React.memo` to prevent re-renders when only other cells change.

New props:
```typescript
interface WellCellProps {
  well: WellData
  isSelected?: boolean  // well is filled/assigned (green highlight)
  isHovered?: boolean  // well is in drag preview (blue outline)
  isEditable?: boolean  // false for standard wells
  onMouseDown?: (event: React.MouseEvent) => void
  onMouseEnter?: () => void
}
```

Visual states (all props are optional for backward compatibility):
- **Standard well** (`well.type === 'standard'`): blue style, NOT editable, shows "S". Same as current.
- **Selected/filled well** (`isSelected === true`): `bg-green-200 border-green-500 text-green-800 ring-2 ring-green-300`. Shows sample index if available.
- **Hovered well** (during drag, `isHovered === true && !isSelected`): `bg-blue-50 border-blue-300` with `ring-2 ring-blue-200`
- **Empty editable well** (default): `bg-gray-100 border-gray-300 text-gray-400`, cursor-pointer when editable
- **Empty non-editable well** (no interactive props): same as current empty style

Add `select-none` class to prevent text selection during drag.
Add `cursor-pointer` when `isEditable` is true, `cursor-default` otherwise.

Title tooltip: `${well.id} - ${well.type}${well.sampleIndex ? ` (Sample ${well.sampleIndex})` : ''}`

Use `transition-colors duration-75` for snappy visual feedback during drag.

**Keep backward compatibility:** All new props are optional. When called without interactive props (from the read-only usePlateLayout-based flow), WellCell behaves exactly as before. This preserves existing PlatePanel usage until Plan 05 wires up the interactive mode.

**Update `PlateGrid.tsx` to support interactive mode:**

Add optional interactive props:
```typescript
interface PlateGridProps {
  wells: WellData[][]
  plateNumber?: number
  // Interactive mode (optional)
  selectedWells?: Set<string>
  hoveredWells?: Set<string>
  standardCols?: readonly number[]  // cols that are standards
  onCellMouseDown?: (row: number, col: number, event: React.MouseEvent) => void
  onCellMouseEnter?: (row: number, col: number) => void
  onCellMouseUp?: () => void
}
```

When interactive props are provided:
- Wrap the grid in a `<div onMouseUp={onCellMouseUp}>` with `select-none` class
- For each WellCell, compute `isSelected`, `isHovered`, `isEditable` from the props:
  - `isSelected = selectedWells?.has(well.id) ?? false`
  - `isHovered = hoveredWells?.has(well.id) ?? false`
  - `isEditable = standardCols ? !standardCols.includes(well.col) : false`
- Pass mouse handlers: `onMouseDown={(e) => onCellMouseDown?.(rowIndex, colIndex, e)}`, `onMouseEnter={() => onCellMouseEnter?.(rowIndex, colIndex)}`
- Note: `rowIndex` is the 0-indexed row (0-7), `colIndex` is the 0-indexed column (0-11). The well.col is 1-indexed. Convert: `colIndex = well.col - 1`

When interactive props are NOT provided (backward compatibility):
- Render exactly as before, no mouse handlers, no selection states

**Important:** Do NOT modify the grid layout, column headers, row labels, or legend. Only add interactive behavior on top of the existing visual structure.

Add `select-none` to the grid container div to prevent text selection during drag operations.
