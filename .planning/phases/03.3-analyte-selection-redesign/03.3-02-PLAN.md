  - To determine panel membership: when a panel is loaded with `getWithAnalytes`, we get `selectedPanel.analytes`. But we need membership info for ALL panels, not just the selected one.
  - **Approach:** The `panels` array has panel IDs. The `availableAnalytes` are all analytes for this platform/species. We need to know which analytes belong to which panel. The `useSelectionStore` loads `selectedPanel` with analytes only for the selected panel.

The easiest approach: call `window.electronAPI.panel.getWithAnalytes(panelId)` for each panel to build the map. Do this in a new `useEffect` in AnalyteSelectionPanel or in useAnalyteSelection hook.
  - **Simpler alternative:** Since the `availableAnalytes` list contains ALL analytes for the platform/species, and panels are a subset, we can use the IPC to load each panel's analytes. Add a new state field `panelAnalyteMap: Record<string, Analyte[]>` to the selection store, populated during `loadPanelsAndAnalytes`. Modify `loadPanelsAndAnalytes` to also fetch panel analyte membership.
  - **Chosen approach:** Add `panelAnalyteMap: Record<string, string[]>` (panelId -> analyteId[]) to selectionStore. Populate it during `loadPanelsAndAnalytes` by calling `getWithAnalytes` for each panel. Then in AnalyteSelectionPanel, compute the grouped analytes from this map.

- Add computed method `getPanelAnalyteMap(): Record<string, Analyte[]>` that resolves IDs to full Analyte objects using `availableAnalytes`
