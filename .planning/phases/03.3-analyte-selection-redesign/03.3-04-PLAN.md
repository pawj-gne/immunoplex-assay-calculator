**Create `SampleCountInput.tsx`:**

A composite input with a slider and an editable number field that stay synced.

Props:
```typescript
interface SampleCountInputProps {
  value: number  // committed numeric value (from plateStore.sampleCount)
  max: number  // slider maximum (default 500)
  onChange: (value: number) => void  // called on commit (blur, Enter, slider change)
}
```

**Critical design: Two-state pattern to avoid typing friction.**
- `value` prop is the committed numeric value (drives the slider)
- Internal `displayValue` (string state) is what the text field shows
- User types in the field -> only `displayValue` updates (no external onChange)
- On blur or Enter -> parse `displayValue`, clamp to [0, max], call `onChange(parsed)`
- Slider change -> call `onChange(val)` immediately and update `displayValue`

Implementation:
- Number field: `<input type="number">` with `placeholder="0"`, starts showing empty string when value is 0
- Slider: `<input type="range" min={0} max={max}>`, always reflects committed `value`
- Field styling: `w-24 px-3 py-2 border border-[var(--color-border)] rounded-md text-sm focus:outline-none focus:ring-2 focus:ring-[var(--color-primary)]`
- Slider styling: `flex-1 h-2 accent-[var(--color-primary)]`
- Layout: `flex items-center gap-4` with label "Samples" above
- When value is 0, displayValue should be empty string (blank field, not "0")
- On field change: `setDisplayValue(e.target.value)` (just the string, no parse)
- On field blur: `commitValue(displayValue)` which parses, clamps, and calls onChange
- On field keyDown Enter: same as blur
- `commitValue(raw: string)`: parse with `parseInt`, if NaN or < 0 -> onChange(0) + setDisplayValue(''), else clamp to max and update both

When `value` prop changes externally (e.g., from reset), update displayValue with a useEffect:
```
useEffect(() => { setDisplayValue(value === 0 ? '' : String(value)) }, [value])
```
