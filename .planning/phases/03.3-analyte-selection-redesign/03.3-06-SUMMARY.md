## Accomplishments
- Column headers 4-12 are interactive: clicking toggles all eight wells in the column, and dragging across headers toggles multiple columns in one gesture, with a window-level mouseup teardown so the drag ends cleanly even if release happens outside the grid. The drag's add/remove intent is locked on mouseDown based on whether the starting column is already fully filled, and the add path respects samples-remaining so the plate cannot be over-filled. WellCell gained an `isColumnHighlighted` visual state that previews the hovered column. Page 2's layout collapsed from two side-by-side cards (CalculatorPanel + Plate Preview) to a single CalculatorPanel that renders PlatePanel inline between the form and the itemized volumes, and plateStore.addPlate now sets `activePlate` to the new plate number so the user lands on the plate they just added. The in-panel help text was also updated to document the new column-header gesture.

## Decisions Made
- **Interactive only for non-standard cols:** `isClickable = isInteractive && standardCols && !standardCols.includes(col)` — cols 1-3 (standards) stay inert
- **Add vs remove resolved at mouseDown:** If every well in the first column is already filled, drag action is 'remove'; otherwise 'add'. Intent is stored in `columnDragRef` and applied uniformly as the user drags across subsequent headers
- **Respect samples-remaining on add:** `applyColumnAction` early-returns when action is 'add' and `getSamplesRemaining() <= 0`, preventing header drag from over-filling
- **Window-level mouseup teardown:** End-of-drag is handled by a `window.addEventListener('mouseup', ...)` effect so release outside the header row still resets the drag
- **Layout consolidation:** PlatePanel moved out of App.tsx's Page 2 JSX and into CalculatorPanel as a sibling section between CalculatorForm and ItemizedVolumeDisplay, each separated by an hr; the "Plate Preview" heading and its wrapping card were removed
- **Auto-navigate on addPlate:** plateStore.addPlate now sets `activePlate: nextPlate` so newly added plates become the active view
