## Reproducibility / Binary Diff Stability

Two consecutive runs of `npm run fixtures:panels` produced byte-identical `all-panels.xlsx` files (verified via `diff -q`). This means:

- Committed-binary diffs are meaningful — `git diff templates/panels/all-panels.xlsx` indicates real content change, not write-timestamp noise.
- Threat T-13-07 (Repudiation / non-determinism) is in practice a non-issue under xlsx 0.18.5's `aoa_to_sheet` + `writeFile` path. If the project switches to `XLSX.write` to a Buffer + `fs.writeFileSync` later, this property should be re-verified.

## CSV Parsing Surprises

None encountered:

- No quoted cells with embedded commas in any of the 16 source CSVs (verified by inspection of `bio-rad-human-panel-1.csv` and spot-checks of others).
- No BOM markers — UTF-8 read via `fs.readFileSync(..., 'utf-8')` produced clean rows.
- One quirk preserved verbatim: `bio-rad-human-panel-1.csv` row 2 column 2 is the string `"Bio-Rad "` with a trailing space. The script does not trim cell values — it round-trips the source CSV's bytes as-is. The parser (Plan 13-03 / 13-04) will own normalization. This is intentional separation-of-concerns: the generator is a faithful CSV→XLSX bridge, not a sanitizer.
- Trailing empty line at end of each CSV is dropped by `csvToRows` filter (`idx < arr.length - 1 || line.length > 0`).
